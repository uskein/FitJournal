El informe es una función nueva pdfService.exportReport(from, to) con HTML A4 multipágina (2 páginas, page-break-after) renderizado por expo-print — misma mecánica que las exportaciones existentes, sin módulos nativos nuevos (compatible Expo Go). Botón: Progreso → «📊 Informe PDF (30 días)». Estimación: ½–1 sprint (generación + botón + testeos).
