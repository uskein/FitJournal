La nueva función: "Mi Semana"

Sí es posible y ya está implementada en la app:

PasoCómo
Agregar semanasPestaña Semana 🗓️ → "➕ Nueva semana". Cada semana es un registro con su rango lun-dom.
Relacionar rutinasToca cualquier día del plan para asignarle una de tus rutinas (o crear una nueva).
Ver lo hecho vs lo de esta semanaCada día planificado se marca ✅ si hay sesión finalizada ese día; arriba ves el % de cumplimiento y los datos de la semana (sesiones, series, volumen).
Exportar progresoBotón "📄 Exportar plan" genera el PDF del plan + progreso real (mockup plan-semanal.html).

Todo funciona en Expo Go (sin módulos nativos nuevos): la persistencia usa la base de datos local (expo-sqlite) con la migración 005.
